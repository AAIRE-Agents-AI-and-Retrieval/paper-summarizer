# About this folder

`paper_docs/` is the original SciSum project's research record, copied on 2026-11-17. References to the original
project's repositories, commit ids and host names were removed, with the log rows that only recorded repository
maintenance; every number, finding and caveat is unchanged. It covers
Students A, B and C, the improvement rounds that produced `prefcc`, and the agent experiments.

File paths, commands and scripts named in it refer to the original project's layout. Some do not exist here:
the reactive and outer-loop agent experiments, round-specific analysis scripts, and `scripts/paper_tables.py`.
How to run things now is in `docs/`. Read this folder for what was measured, why, and with what caveats.
Start with `14_student_c_what_worked.md` (also in `docs/WHAT_WORKED_ON_C.md`), then `13_recipe_for_any_student.md`
and `06_findings.md`.
