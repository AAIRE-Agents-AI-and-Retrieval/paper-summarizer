# Source of truth for the paper

Everything in this folder is derived from artifacts the pipeline wrote, not from recollection.
Numbers are copied from `data/results_index.json`, `data/evaluations.csv` and `data/val_loss.csv`,
which are regenerated by `scripts/paper_tables.py` from `runs/*/run.json`, `runs/*/state.json`,
`runs/*/metrics.jsonl`, `runs/*/eval/*.json`, the judge files and `state/build-<model>.json`.

**Rule for maintaining this folder**: a number appears here only if a file in the repository
contains it. If a claim cannot be traced to an artifact, it belongs in `07_threats_to_validity.md`
as an open question, not in the results.

| File | Contents |
|:--|:--|

| `02_method.md` | training setup, loss, schedule, adapters, infrastructure |
| `03_evaluation_protocol.md` | every metric, how it is computed, and what it cannot show |
| `04_experiments.md` | the configuration of each run, as recorded |
| `05_results.md` | all measured numbers |

## Where things stand (2026-11-16)

The project's experiments are complete. Round 4 (below), the last one, ended on 2026-11-16 with a null result, so `prefcc` stays
the recommended model. `13_recipe_for_any_student.md` turns the results into a recipe for other students, and
`14_student_c_what_worked.md` is a self-contained account of what worked on Student C.

**Recommended model: `prefcc`.** It continues Student C (Qwen3.5-9B, LoRA, SFT on 20,000 papers) with
DPO plus a likelihood term, on 1,233 preference pairs chosen by a reward that combines fact recall,
ROUGE-L, unsupported numbers, length and a claim check against the whole paper. Judged on the mean of
its two seeds, it is the only training arm of rounds 1–3 that meets all four criteria fixed in advance.
Round 4's `r4b` also meets them, but it is not better than `prefcc` on any measure (F13).
Sources: `11_reward_selected_distillation.md` (rounds 1–3), `12_reactive_training.md` §8 (second seed).

| `prefcc` − C, 1,246 test papers | two-seed mean | seed 1 | seed 2 |
|:--|--:|--:|--:|
| fact recall (899 papers, two question sets) | **+0.0262** [+0.0201, +0.0322], p = 0.0001 | +0.0327 | +0.0197 |
| length ratio to the teacher (criterion 2: 0.90–1.10) | 0.988 | 1.017 | 0.959 |
| ROUGE-L / BERTScore (criterion 3: ≥ −0.010) | −0.0053 / −0.0085 | −0.0054 / −0.0070 | −0.0052 / −0.0099 |
| unsupported-or-contradicted share (criterion 4: not above C) | +0.0045 [−0.0003, +0.0093] | +0.0003 | +0.0087 (fails) |
| NLI (300 papers; reported, not a criterion) | −0.0243 [−0.0341, −0.0152] | −0.025 | −0.0237 |
| judge faithfulness, 1–5 (499 papers; reported) | −0.090 [−0.139, −0.039] | −0.090 | −0.090 |

On the same fact test the teacher recalls 0.6082 and C 0.5708. `prefcc` seed 1 is level with the
teacher (−0.0047 [−0.0132, +0.0034]).

| What was tried | Outcome | Where |
|:--|:--|:--|
| Round 1: reward-selected SFT targets; DPO on fact-ranked pairs | DPO +0.071 recall, but mostly by writing longer (1.26× the teacher) with more unsupported statements | `11`, F8 |
| Round 2: length control in the pairs, the loss, or both | +0.017 to +0.030 recall at the teacher's length; no arm meets all four criteria | `11`, F9 |
| Round 3: claim check in the reward (`prefcc`), second seeds | `prefcc` meets all four criteria; pair order alone moves recall by 0.013–0.020 | `11`, F10 |
| C ↔ `prefcc` weight blends (w = 0.5, 0.75) | Both meet all four criteria (+0.020, +0.029 recall); neither is better than `prefcc` | `12` §8, F11 |
| An LLM agent steering DPO during training (`prefccrx`) | Not better than fixed training on the same pairs; fails criterion 4 | `12` §8, F12 |
| Round 4: an LLM designer proposes arms, scored on a validation set V; a blind audit of the pairs | Null result. `r4b` (claim weight 3) meets all four criteria and ties `prefcc` (recall −0.0025 [−0.0074, +0.0024]). `r4a` (teacher-chosen pairs only) fails criterion 4 and recalls 0.017 less | `12` §9, F13 |

Open caveats (details in `07_threats_to_validity.md`):
- `prefcc`'s NLI and judge-faithfulness scores stay below C's.
- The training reward and the evaluation use the same kind of claim check, with the models swapped.
- The 1,246 test papers were reused across rounds.
- There is no human evaluation.

```bash
srun -p short -c 4 --mem=16G -t 15 .venv/bin/python scripts/paper_tables.py
```

## What this folder does not contain

It holds aggregate results, per-system tables and per-paper *scores*. It holds no teacher summaries, fact-check
questions or gold answers, and no text excerpted from papers; those are in `data/`, for internal use only
(`docs/DATA.md`). Model checkpoints, token shards, run logs and raw prediction files are not here either.
